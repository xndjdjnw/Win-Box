# Streamline Desktop Shell

一个面向 Windows 桌面端的影视客户端界面原型：React + TypeScript + Vite。项目只提供本地演示数据、界面导航和受限的配置导入草稿；不包含媒体抓取、绕过平台限制、访问未授权源或播放受保护内容的实现。

## 功能

- 首页、搜索、详情、设置与来源管理界面
- 可筛选的本地演示目录
- 来源 JSON 草稿校验：仅接受 `name` 和 `address`，仅允许 `https://` 或 `demo://`
- 导入后默认停用；不会在浏览器中发出请求
- 明确的授权与隐私提示

## 运行

需要 Node.js 20+ 与 npm：

```bash
npm install
npm run dev
```

运行生产构建：

```bash
npm run build
```

## 接入桌面容器

此项目目前是 Web UI。若要作为 Windows 应用发布，可在后续阶段使用 Tauri 或 Electron 包装。建议将所有网络访问放在受权限控制的服务层，并实现：域名允许列表、用户可见的来源授权、超时与内容安全策略、最小化日志和隐私告知。

## 合规边界

只接入你有权访问及使用的来源。不要将本项目用于抓取、聚合、分发未授权内容，或规避服务条款、数字版权管理或访问控制。
